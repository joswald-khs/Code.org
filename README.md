# Code.org

This is an attempt to provide some code based of the Code.org examples for AP Computer Science A that will work inside BlueJ and Processing. You'll need to set up BlueJ for use the Processing Library in order to run these examples. 

[`Painter`](/Painter/) is based of the `Painter`/`PainterPlus`/`SpiralPainter` examples in Unit 1. Make sure to read the README for usage instructions.
